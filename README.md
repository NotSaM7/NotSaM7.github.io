## 🚀 About
Personal portfolio showcasing my software engineering work — spanning full-stack applications, data-driven systems, machine learning/NLP projects, and quantitative finance tools.

## 🛠️ Tech Stack
- **HTML5 & CSS3**: Custom dark-mode design system with responsive layouts and subtle micro-animations.
- **JavaScript (ES6+)**: Interactive UI elements, smooth scrolling, and dynamic features.
- **Typography & Assets**: Modern Inter font paired with sleek SVG iconography.

```

├── js/
```

---

## 💻 Running Locally
No build process or dependencies required. Simply open `index.html` in any web browser, or serve locally using VS Code Live Server / Python:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
